# Mi Portafolio — React + Vite

Portafolio personal construido con React y Vite. Muestra proyectos, stack técnico y contacto. Está diseñado para ser responsive y accesible.

Requisitos
- Node.js 18+ y npm

Instalación y ejecución en desarrollo
```bash
npm install
npm run dev
```

Producción
```bash
npm run build
npm run preview
```

Qué contiene
- `src/components`: componentes React (Header, Hero, Projects, etc.)
- `src/data`: datos de proyectos y tech stack

Notas rápidas
- Uso Tailwind para utilidades de diseño. Para ajustar el tema o colores, revisa las clases en los componentes y `index.css`.
- Accesibilidad: incluye enlace "Saltar al contenido", manejo de foco en modales y atributos ARIA en la navegación móvil.

Si quieres, puedo:
- Unificar colores y tokens (Tailwind config), o
- Preparar una versión en TypeScript.
